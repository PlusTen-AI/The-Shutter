# 화면 글자용 한글 글꼴 (기능 18, design §0)

`video.edit`의 화면 글자(이름 카드 · 숫자 · 댓글 · 자막)는 여기 있는 글꼴(.ttf · .otf · .ttc)로 그린다 — 이미지 빌드 때
`/opt/shutter/fonts/`로 들어간다. 이름에 Bold가 든 파일이 굵은 글, Regular·Medium이 보통 글. 없으면 글자가 든 내보내기는
오류로 멈춘다. 공개 저장소에 들어가므로 OFL 같은 재배포 가능한 글꼴만.

- 넣은 것: Pretendard v1.3.9 Bold · Regular(OFL 1.1, `Pretendard-LICENSE.txt`) — 보스, 세션 #18.
